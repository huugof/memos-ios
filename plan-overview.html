Design Goals

⚡

Instant Capture

App opens to a blank editor with blinking cursor. Zero taps to start typing.

📋

Clean Organization

Notes grouped by Today → Month → Year. One-line previews, tags inline.

🔍

Smart Search

Contextual suggestions, filtered results with count, highlighted matches.

🎨

Apple Notes Aesthetic

Dark theme, rounded cards, yellow accent, minimal UI chrome.

Key UI Elements

Editor Toolbar

← Back (upper left) — returns to All Notes, saves draft locally
↩ Undo — standard undo
⬆ Share — iOS share sheet
••• Menu — attach photos, files
✓ Done (yellow, upper right) — sends/saves to server, returns to All Notes

All Notes Screen

Title + count at top ("All Notes — 142 Notes")
••• Menu (upper right) — Select Multiple, Refresh, Show Attachments, Settings
Grouped list — sections: Today, month names, year labels
Note rows — bold title, date, 1-line preview, tag pills
Bottom bar — search pill (left+center) + new note FAB (bottom right)

Search

Empty state — "Suggested" filters: Tags, Attachments, Checklists
Typing — "X Found" count, results with highlighted matches
Cancel — ✕ button dismisses search

New Files (8)

  • MemoChat/ViewModels/UnifiedNote.swift— Wraps Draft + ServerMemoSummary into single display type
  • MemoChat/Views/NotesNavigationRoot.swift— Top-level: NavigationStack, stores, lifecycle
  • MemoChat/Views/AllNotesView.swift— Grouped note list with menu + search bar
  • MemoChat/Views/NoteEditorView.swift— Full-screen editor with toolbar + attachments
  • MemoChat/Views/NoteSearchView.swift— Search overlay with suggestions + results
  • MemoChat/Views/Components/NoteRowView.swift— Note list row: title, date, preview, tags
  • MemoChat/Views/Components/NoteDateGrouping.swift— Groups notes by Today/month/year
  • MemoChat/Views/Components/NotesMenuSheet.swift— All Notes menu: select, refresh, attachments, settings
